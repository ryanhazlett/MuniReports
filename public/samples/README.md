# Sample Reports

Drop the four sample PDFs here:

- austin.pdf — City of Austin, TX
- roundrockisd.pdf — Round Rock ISD, TX
- chicago.pdf — City of Chicago, IL
- mud.pdf — Harris County MUD #6, TX

To generate them:
1. Go to munireports.com/builder (after this is deployed and you're logged in)
2. Search and generate a report for each issuer
3. Click Print / PDF
4. In the print dialog, uncheck "Headers and footers"
5. Save as PDF with the filename above
6. Drop the PDF into this folder
7. Commit and push — the homepage download links will work immediately
